### Architecture notes for future fixes

**Customer home screen (`customer/lib/ui/home_screens/home_screen.dart`)**
- Wrapped in `GetX<HomeController>` — entire screen rebuilds on any observable change
- `isLoading = true` initially, set to `false` after `getServiceType()` completes
- Vehicle tile ListView: `itemCount: controller.serviceList.length`; each tile in `Obx`
- Selected tile comparison: `controller.selectedType.value.id == serviceModel.id` (string comparison, not object identity)
- Tile colors: selected → `AppColors.lightsecondprimary` (Gold); unselected → `controller.colors[index % 3]` (pastels)

**Driver home screen (`driver/lib/ui/home_screens/home_screen.dart`)**
- Bottom nav: 4 tabs (New, Accepted, Active, Completed) — selected tab uses `lightsecondprimary` (Gold)
- City tab = `NewOrderScreen` — only starts geo stream when `Constant.currentLocation != null` AND `driverModel.zoneIds` non-empty

**Driver geo orders (`driver/lib/utils/fire_store_utils.dart` line 448)**
- `getOrders()` uses GeoFlutterFire `within()` with Firestore real-time listener
- Query requires valid `serviceId` (not null) AND `zoneIds` (non-null, non-empty array)
- With null/empty `zoneIds`, Firestore throws and stream never emits → StreamBuilder stays in `waiting` forever
- This is why the null-guard in `new_orders_screen.dart` is critical

**LanguageName parsing (both apps)**
- Firestore service documents use `{name: "Economy", language_code: "en"}` (NOT `{title: ..., type: ...}`)
- `LanguageName.fromJson()` now maps: `language_code`/`languageName`/`type` → `.type`; `name`/`title` → `.title`
- `localizationTitle()` now safe: uses `where().isNotEmpty ? .first` with English fallback, never throws
